# Aplicação para Rede LoRa - Laboratório IoTec (UNIVALI)

Este é o repositório oficial da aplicação final desenvolvida para a rede de sensores LoRa do laboratório **IoTec** da Universidade do Vale do Itajaí (UNIVALI - Campus Itajaí). 

O sistema foi projetado para atuar no monitoramento ambiental, recebendo, processando e estruturando os dados coletados pela rede de sensores de forma eficiente.

## 👨‍💻 Autoria
Todo o código-fonte desta aplicação, bem como a arquitetura do sistema, foram desenvolvidos integralmente pelo pesquisador bolsista **Samuel Cesário Pereira Trizotto de Andrade**.
